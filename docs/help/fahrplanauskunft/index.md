# Fahrplanauskunft

Die Fahrplanauskunft stellt die plattformunabhängige Datenbasis für Adress- und Haltestellensuche, nahe Haltestellen, Verbindungen, Abfahrten und regionale Echtzeit bereit. Schritt 1 liefert keine neue Oberfläche; die späteren UI-Schritte verwenden diese Services.
