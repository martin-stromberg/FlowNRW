# Automatische Monitoraktualisierung

Ein gespeichertes Intervall hält geöffnete Abfahrtsmonitore und Favoritentafeln im aktiven App-Fenster aktuell. Wiederaufnahme erneuert veraltete Daten; iOS kann zusätzlich begrenzte Favoritenaktualisierungen im Hintergrund ausführen. Die manuelle Aktualisierung bleibt verfügbar.

- [Technischer Ablauf](ablauf-technisch.md)
- [Speicherung und iOS-Prüfanleitung](installation.md)
- [Nachweise für Wiederaufnahme und Hintergrundkoordination](verification-lifecycle/index.md)

Diese Hilfe beschreibt die Implementierung. Native Windows-Testbelege werden gesondert dokumentiert; die iOS-Geräteprüfung liegt beim Nutzer.
