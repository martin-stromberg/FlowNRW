# Haltestellen- und Verlaufskarte

[Bedienung und technischer Aufbau](beschreibung.md) · [Fehlerhilfe](troubleshooting.md)

Gemeinsame Kartenansicht für Haltestellensuche, Favoriten und gelieferte Verbindungsverläufe mit lokalem Leaflet und nativem Kachel-Gateway. Windows wird nativ geprüft; die iOS-Geräteabnahme einschließlich des Lade-Watchdogs bleibt beim Nutzer.
