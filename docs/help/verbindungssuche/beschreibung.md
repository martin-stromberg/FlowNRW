# Verbindung suchen

Wählen Sie Start und Ziel manuell. Eine Standortfreigabe ist dafür nicht erforderlich.

1. Geben Sie unter „Start: Adresse oder Haltestelle“ einen Ort ein, etwa „Gelsenkirchen Hbf“, und drücken Sie „Suchen“.
2. Wählen Sie den passenden Treffer. Die Treffer zeigen nur den Haltestellennamen; ein doppelt genannter Ortsname („Münster (Westf), Münster (Westf) Hbf") wird als „Münster (Westf) Hbf" angezeigt und interne Kennungen werden nicht gezeigt. Der gewählte Ort steht anschließend im Eingabefeld.
3. Wiederholen Sie dies unter „Ziel“, etwa für „Essen Hbf“.
4. Drücken Sie „Verbindungen suchen“. Die Suche verwendet den aktuellen Zeitpunkt. Während „Verbindungen werden geladen …“ angezeigt wird, warten Sie auf das Ergebnis.
5. Unter „Verbindungen“ sehen Sie geplante Zeiten („Soll“), verfügbare tatsächliche Zeiten („Ist“), Umstiege, Linien, Betreiber und Fußwege. Tippen Sie eine Verbindung an, um „Verbindungsdetails“ zu öffnen.
6. Die Zurück-Navigation führt über die Ergebnisse zur Suche. Ihre Auswahl bleibt erhalten. Ändern Sie eine Eingabe, müssen Sie diesen Endpunkt erneut übernehmen; bisherige Verbindungen werden verworfen.

## Position auf der Karte wählen

Drücken Sie für Start oder Ziel die Karten-Schaltfläche neben dem Eingabefeld. Ein modales Fenster mit einer OpenStreetMap-Karte öffnet sich. Tippen Sie die gewünschte Position an; der gesetzte Punkt lässt sich durch erneutes Antippen korrigieren. Mit „Übernehmen“ wird die Position in eine Adresse umgewandelt und der ermittelte Ortsname erscheint im Eingabefeld. „Abbrechen“ schließt die Karte ohne Übernahme.

## Aktuellen Standort verwenden

Drücken Sie die Standort-Schaltfläche neben dem Eingabefeld. Nach der Freigabe wird die ermittelte Position in eine Adresse umgewandelt und der ermittelte Ortsname erscheint im Eingabefeld.

## Angaben richtig lesen

Die Zeiten enthalten Datum und Zeitversatz zur Weltzeit; angezeigt wird die deutsche Ortszeit, auch bei Fahrten über Mitternacht. Details zeigen einzelne Teilstrecken, Abfahrt und Ankunft, Bahnsteige sowie verfügbare Umstiegs- und Fußwegangaben. „unbekannt“ oder „keine Echtzeitdaten“ bedeuten, dass keine entsprechende Angabe geliefert wurde. Daraus lässt sich keine Pünktlichkeit ableiten. „Ausfall gemeldet“ bzw. „Ausfall“ kennzeichnet einen gemeldeten Ausfall.

„Quelle“, „Datenstand“ und „Datenalter“ helfen bei der Einordnung. „Ersatzquelle (Fallback)“ bezeichnet eine ersatzweise genutzte Quelle. „Veralteter Cache“ kennzeichnet ältere zwischengespeicherte Daten. Eine „Anbieterwarnung“ weist auf möglicherweise unvollständige Angaben hin. Es gibt keine automatische Aktualisierung; suchen Sie für einen neuen Datenstand erneut.

## Wenn die Suche nicht weitergeht

- „Verbindungen suchen“ ist gesperrt: Übernehmen Sie Start und Ziel ausdrücklich; bloßes Eintippen genügt nicht.
- „Keine Treffer. Bitte Eingabe ändern.“: Ergänzen Sie Stadt oder Haltestellenname und suchen Sie erneut.
- „Adresse konnte nicht ermittelt werden.“: Die gewählte Position konnte nicht aufgelöst werden; wählen Sie einen anderen Kartenpunkt oder suchen Sie manuell.
- „Keine Verbindungen gefunden. Bitte erneut suchen.“: Prüfen Sie die ausgewählten Orte und versuchen Sie die Suche erneut.
- Eine Suche ist fehlgeschlagen: Prüfen Sie Ihre Internetverbindung und wiederholen Sie sie. Die Datenquelle kann vorübergehend nicht erreichbar sein.

Die Oberfläche lässt sich scrollen; Treffer und Ergebnisse umbrechen längere Texte. Felder und Schaltflächen sind beschriftet. Eine native iOS-Prüfung einschließlich VoiceOver und vergrößerter Schrift steht noch aus. Favoriten, Abfahrtsmonitor und Tickets sind in dieser Oberfläche nicht enthalten.
